# かんたん家計簿

Vue 3 + TypeScriptで作成した家計簿アプリのフロントエンドです。

## 画面

- 月間一覧：月別合計、日別金額カレンダー、カテゴリ別集計
- 日別詳細：選択日の支出と品目内訳
- 支出入力：日付、店舗、カテゴリ、品目、単価、個数、合計金額

## 開発

```bash
npm install
npm run dev
```

型チェックを含む本番ビルド：

```bash
npm run build
```

## API差し替え

画面は `src/api/expenseApi.ts` の `ExpenseApi` インターフェースだけを参照します。現在は同ファイル内のモック実装が固定データを返しています。Laravel APIを実装した後は、HTTP通信を行うクラスへ差し替えることで画面側を維持できます。
