# 共通タイポグラフィ

家計簿とクレカ管理の `src/typography.css` は同一内容を維持します。独立してビルドできるよう、他リポジトリのファイルには依存しません。変更する場合は両方へ反映してください。

| 用途 | 共通基準 |
| --- | --- |
| フォント | Noto Sans JP。未読込時はヒラギノ角ゴ・游ゴシック・sans-serif |
| 本文・ボタン・表 | 14px |
| 補足・ラベル・モバイルナビ | 12px |
| フォーム入力 | 16px |
| 小見出し／セクション見出し | 18px／20px |
| ページ見出し | 24〜32px（画面幅で調整） |
| 主要な合計金額 | 32〜36px（画面幅で調整） |
| カレンダー内の金額 | 11px（7列を維持。全額は明細で確認） |
| 太さ | 400／500／600／700 |
| 行間 | 本文1.65、見出し1.3、コンパクト表示1.4 |

サイズはrem指定で、ブラウザーの文字サイズ設定に追従します。数字も本文と同じ書体を使い、金額にはtabular-numsを適用します。フォントの外部配信を利用できない場合も共通のフォールバックで表示します。
